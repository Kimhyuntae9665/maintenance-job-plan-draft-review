      정확한 검토 바인딩
      

      

      근거가 있는 값 복원 · 검토 반환
      원본은 바뀌지 않습니다. 셀과 선언한 규칙이 뒷받침하는 값만 저장할 수 있습니다. 다른 값은 원본 확인이 필요합니다.
      

      가상 원본 버전 변경
      한 행의 새 가상 버전을 명시적으로 등록합니다. 원본 패킷 파일은 변경하지 않습니다.
      

      선택한 JSON 초안
      표시한 선택 행만 포함합니다. create/update/delete 작업이나 전체 스냅샷 의미가 없습니다. 빠진 행은 삭제를 뜻하지 않으며 준비 확인은 대상 시스템의 가져오기 영수증이 아닙니다.
      초안 준비 확인 내역
      

      저장된 모델 제안
      복사는 수락이 아닙니다. 원본과 다른 편집 값은 수락을 막습니다. 실시간 추론은 없습니다.
      

      필드별 검증 근거
      구조 · 의미 비교 · 백엔드 판단을 구분합니다. 의미의 정확성이나 가져오기 권한을 자동 승인하지 않습니다.
      

      검토 내역
      

      프로토타입 범위와 원본 처리
      TSV/JSON만 지원합니다. 수락한 빈도는 예정일이나 실제 작업 준비를 확정하지 않습니다. 역할명은 담당 개인이나 작업 권한을 뜻하지 않습니다. 수식과 링크는 실행하지 않는 원문 데이터입니다.
