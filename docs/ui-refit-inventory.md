# P09 화면 기능 목록과 현재 캡처 계획

사용자가 승인한 기존 v2 개발 화면의 색상·간격·패널 구성을 기준으로 한다. 코드/모델 결과/원본 TSV와 JSON은 화면 변경으로 다시 평가하거나 수정하지 않는다.

| 순서 | 기능 | 확인할 경계 | 새 실제 화면 |
|---|---|---|---|
| 1 | 기본 원본 행 선택과 사이트 필터 | 열람과 내보낼 행 선택은 별개 | 원본/결과 두 패널 |
| 2 | 원본 셀과 변경 필드 비교 | 파일·행·셀·바이트 위치 불변 | 정확한 셀 근거 |
| 3 | 정규화 빈도와 검토 | 월/일/운전시간 구별, 미예약 상태 | 검토·현재 영수증 |
| 4 | 불명확 이벤트/충돌 | 수락 금지, 질문 노출 | 차단 사유 |
| 5 | 선택된 행 JSON 초안 | 필터 이후 정확한 ID와 개수 | 범위·준비 확인 내역 |
| 6 | 저장된 v1 모델 거절 | 구조/의미/백엔드 사유 구분 | 필드별 검증 |
| 7 | 새 원본 버전과 이전 검토 | 이전 수락·제안 재사용 금지 | 이전 내역/현재 버전 |
| 8 | v2 저장 제안 | 유효한 구조는 의미 승인 아님 | 원본/제안 두 패널 |
| 9 | v2 운전시간 제안 | 500 운전시간은 벽시계·예정일 아님 | 필요한 의미 검토 |
| 10 | 390px 실제 화면 | 한 줄 한국어 제목, 키보드/포커스, 표 스크롤 | 모바일 |

CPU CI와 로컬 Chrome 검증을 구분한다. 이전 캡처는 역사적 증거로 보존하며 현재 화면인 것처럼 표시하지 않는다. 새로운 모델 호출은0회다.
