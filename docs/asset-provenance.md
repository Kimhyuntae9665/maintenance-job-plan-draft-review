# Diagram provenance

Five original geometric glyphs represent actual code relationships: Sources → Cells → Rules → Review → Draft. Sources are immutable TSV/JSON text; source.mjs creates exact cells; normalize.mjs proposes typed fields; server.mjs binds human inspection; export returns a local JSON draft. This is an original prototype graph, not IBM's private architecture or a Maximo integration.

The dotted dark background, rounded white glyph cards, curved arrows and short names below glyphs follow the approved logo-flow style. All glyphs are embedded original MIT artwork; no vendor logo is used. PNG and editable SVG retain aspect ratio. The diagram makes no model or evaluation claims.
