# CPU review UI maintenance

This maintenance pass made zero inference calls and used only existing development captures, stored v1/v2 outputs and explicitly synthetic browser responses. The blocked independent challenge was not materialized, read, recreated or scored.

Actual Chrome reproduced two frozen v2 display defects: failed attempts were described as not attempted, and incomplete archived content was labeled as requiring semantic review. The new `review-ui/` overlay separates not attempted, failed, incomplete, invalid JSON/schema, stale source and structurally valid but unaccepted suggestions. It independently checks the raw content against the displayed capture/hash/C9 quote/byte span. Backend copies do not repair model meaning. A typed summary accompanies usable raw suggestions, while a person must still judge semantics. This read-only desk has no acceptance, export or inference endpoint.

`npm run v2:desk` now opens the overlay. `npm run v2:desk:frozen` retains the original frozen UI for replay, on the same port; run one at a time. All 28 files in the v2 protocol freeze remain byte-identical, including the old desk, prompt, schema, runtime, source builder, grading contract and original development labels. The three development outputs/results and twelve v1 outputs/results are unchanged. The default runtime UI and receipt metadata changed after evaluation; the v1 model input, parser/normalizer and validation contract did not change. The original experiment freeze still records its original file hashes.

Chrome also reproduced and verified these default-desk repairs:

- Download acknowledgments retain exact capture IDs/count, source file/revision/hash, proposal/review bindings, filter, scope hash, draft hash and pre-download snapshot version. History separately shows whether source/review bindings remain current and whether the snapshot matches today's selected scope. Historical evidence cannot reauthorize a row. A download acknowledgment is not a target import receipt.
- Stored-model rejection evidence names differing fields and raw versus source-supported values, separating response structure, exact source binding, bounded grammar/literal comparisons and authoritative backend blockers/review boundaries. The grammar comparison is not general semantic grading or model repair.
- Source revision changes reconcile both open and selected IDs to the currently visible authorized set. Filtered-out rows cannot remain in the detail pane or export selection. Historical review/download evidence remains available.
- The header names the current capture/revision and all admitted source revisions. Archived same-capture model output names its original revision and has no candidate authority. Malformed, absent or cross-capture stored input cannot break the deterministic desk or expose another capture's output.
- Readable typed summaries preserve calendar versus operating-runtime units, explicit whichever-first and unresolved event/relation states. Original glyphs still represent generic components; the README diagram's dashed Model branch is optional offline comparison/stored inspection, not live inference or automatic acceptance.
