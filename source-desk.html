내 TSV/JSON으로 초안 만들기

고정 예제 검토로 돌아가기

새 로컬 원본을 등록하고 원문 → 규칙 기반 초안 → 근거 확인 → JSON 초안을 검토합니다. 원본 패킷과 별개인 메모리 안의 작업 공간이며 서버 재시작 시 초기화됩니다. 실제 정비 승인·일정 계산·대상 시스템 가져오기는 없습니다. 개인정보·비밀·실제 운영 승인 정보를 넣지 마세요.

1. 원본 입력

UTF-8 .tsv/.json 파일 또는 원문 붙여넣기 · 원문 최대 1 MiB · 문자열 셀만 허용 · TSV는 한 줄에 한 행, 탭 구분이며 따옴표 해석은 하지 않습니다. JSON 형식은 {"rows":[{...}]}입니다.

파일 내용은 아래 편집기에 표시되며, 등록 버튼을 눌러야 입력됩니다.

필수 열: row_id, equipment_id, organization, site, task_text, frequency, responsible_role. 숫자 ID는 문자열로 유지합니다. 지원 빈도 예: Monthly, 매월, 500 operating hours. 수식과 링크는 실행하지 않습니다.

같은 ID·이름 공간에 새 버전을 등록하면 이전 원문과 영수증은 이력으로 남습니다. 같은 버전의 다른 내용은 충돌로 유지됩니다. 빈 버전은 명시적으로 현재 행을 제거할 수 있으며, 기존 원문을 덮어쓰지 않습니다.

2. 등록한 원본 · 행 선택

원본 · 버전행문자열 장비 ID사이트열람
등록 원문과 SHA-256 이력

3. 원문 근거 · 규칙 초안 검증

필드정확한 문자열원본 셀 · 바이트 범위

빈도 · 미확인 항목 · 충돌

미확인 항목은 그대로 남습니다. 검토한 초안도 일정·실제 작업 준비·담당 개인·작업 권한을 확정하지 않습니다. 충돌이 있으면 검토와 내보내기를 막습니다.


4. 현재 검토한 행 JSON 초안
현재 열람한 한 행만 내보냅니다. 등록·버전 변경만으로 검토되거나 내보내지지 않습니다. 수식·링크는 원문 문자열로 남으며 JSON에만 포함됩니다.
